# Code Room 0.3.5

Esta versão mantém o Code Room gratuito e com código aberto sob MIT. Cada pessoa conecta as próprias IAs e usa a própria cota.

## O que mudou

- O Nico em Modo Piloto pode criar, editar e mover arquivos do projeto usando as ferramentas liberadas para o agente. Uma pasta fora do projeto exige autorização específica no pedido.
- Projetos e equipes podem reutilizar agentes existentes. O Nico propõe trazer o agente para outro projeto em vez de tentar cadastrá-lo de novo na mesma IA.
- O chat mostra o diagnóstico da execução e orientações mais claras para falta de login, CLI ausente, ausência de resposta, ferramenta negada e tempo esgotado.
- A interface mostra apenas os agentes do projeto em foco, melhora o acompanhamento de tarefas e entregas e mantém a prévia de arquivos e diferenças antes da revisão.
- O Cenário ganhou personagens e estados mais vivos; o rádio perdeu a borda quadrada quando toca.
- O pacote Windows e a rotina de atualização receberam correções de montagem, verificação de arquivos e testes de primeira abertura.

## Antes de começar

Instale e faça login na CLI da IA que deseja usar. Em **Conexões**, use **Testar resposta**. Para editar arquivos pelo Nico, selecione um projeto e ligue o **Modo Piloto**. Navegador, programas e outras ferramentas exigem liberação por agente.

O instalador ainda não tem assinatura digital. A instalação e a atualização em uma segunda máquina com dados existentes devem ser conferidas antes de depender da versão em trabalhos importantes.
