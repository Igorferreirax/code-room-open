# Code Room 0.3.7

Versão focada em fazer o Nico agir de verdade em pastas do seu computador. Continua gratuita e com código aberto sob MIT.

## O que mudou

- **“Organize a minha Área de Trabalho” funciona.** O Code Room ganhou uma ferramenta própria para criar pastas e mover ou renomear arquivos (PDF, imagem, planilha…). Ela só age nas pastas que você autorizou naquela tarefa, nunca apaga e nunca sobrescreve. Conferido com Claude e Codex reais numa Área de Trabalho no OneDrive com acento no nome.
- **Escolha a IA, o modelo e o esforço do Nico no topo do chat.** O botão ao lado do nome mostra, por exemplo, “Claude · opus”. Cada IA guarda a sua escolha.
- **Pasta fora do projeto, direto no chat.** O Nico pergunta num cartão: **Só ver** (lê e não altera nada, sem Modo Piloto), **Ver e editar** ou **Cancelar**. Depois de autorizar, ele não pergunta de novo na mesma conversa.
- **Erros visíveis.** Se o envio for recusado, o motivo aparece no chat, em vez de parecer que nada aconteceu.
- **Área de Trabalho certa** mesmo no OneDrive ou com acento no nome.
- **Cenário vivo removido.** A Sala fica com Cenário e Canvas.

## Limites conhecidos

- No Antigravity, mover arquivos ainda não funciona; para organizar pastas, use Claude ou Codex (troque no topo do chat).
- O instalador ainda não tem assinatura digital.
