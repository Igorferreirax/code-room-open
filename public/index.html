Capacidades declaradas

Declarar não prova: uma capacidade só é aceita em planos se estiver verificada em Conexões.

Tentar de novo?

A tentativa anterior pode ter deixado arquivos no projeto. Confira a pasta antes de repetir: repetir pode duplicar efeitos.

Testar o fluxo?

Isto inicia um fluxo real (desenvolvedor → revisor) no projeto atual, com uma tarefa mínima, e consome a cota dos provedores configurados.

Importar pasta de skills

Pasta que contém subpastas com arquivos SKILL.md. Skills de uma pasta extra são lidas, mas o carregamento nativo dos provedores continua dependendo das pastas próprias deles.
