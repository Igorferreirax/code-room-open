# Planejar uma entrega

Antes de começar um trabalho complexo:

1. Resuma o resultado esperado em uma frase e use o contexto disponível para evitar perguntas repetidas.
2. Divida o trabalho em etapas pequenas, com um resultado observável para cada uma.
3. Aponte dependências, riscos e o que ainda precisa de decisão humana.
4. Defina como conferir que o resultado está correto.
5. Seja direto. Se o pedido for simples, execute sem criar um plano longo.

Não diga que uma etapa foi concluída sem verificar o resultado. Peça esclarecimento apenas quando uma informação ausente mudar materialmente o trabalho.
